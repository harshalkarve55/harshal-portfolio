HARSHAL KARVE — PERSONAL PORTFOLIO WEBSITE
===========================================

FILES
-----
index.html      Main website content
style.css       White + blue responsive design
script.js       Mobile menu, active navigation, current year and contact form
assets/         Put your profile photo here as profile.jpg

STEP 1 — OPEN THE WEBSITE
-------------------------
1. Extract this ZIP file.
2. Open the harshal_portfolio folder in Visual Studio Code.
3. Open index.html in your browser.
   Recommended: install the "Live Server" extension in VS Code, right-click
   index.html and select "Open with Live Server".

STEP 2 — ADD YOUR PROFILE PHOTO
-------------------------------
1. Choose a clear professional photo.
2. Copy it into the assets folder.
3. Rename the image to: profile.jpg
4. The photo should ideally be portrait orientation.
   If you use another filename, update the img src in index.html.

STEP 3 — PERSONALIZE YOUR DETAILS
---------------------------------
Open index.html and update:
- About section if you want a different introduction.
- Project descriptions and technology stacks to match what you have actually built.
- Email, GitHub and LinkedIn links in the Contact section.
- College/course details if they change.

Open script.js and replace:
your.email@example.com
with your real email address. Also update the same email in index.html.

For the contact form, this starter website uses mailto: to open the visitor's
email application. It does not send messages to a server. For a live website
contact form, connect a backend or a form service.

STEP 4 — TEST
-------------
- Check all navigation links.
- Test the mobile menu by narrowing the browser window.
- Test the contact form after adding your email address.
- Check your profile photo and project information.
- Test on both desktop and mobile.

STEP 5 — PUBLISH FREE WITH GITHUB PAGES
---------------------------------------
1. Sign in at https://github.com/
2. Create a new public repository, for example: harshal-portfolio
3. Upload index.html, style.css, script.js, README.txt and the assets folder.
4. In the repository, open Settings > Pages.
5. Under Build and deployment, select "Deploy from a branch".
6. Select branch "main" and folder "/ (root)", then Save.
7. Wait for the deployment to finish. GitHub will show your live website URL
   in Settings > Pages.

IMPORTANT
---------
- Use your own photo and real contact links.
- Do not publish private phone numbers or personal information unless you want to.
- Only describe projects and skills accurately. Mark work-in-progress projects
  clearly if they are not complete.
